# Transport alignment snapshots

© OpenStreetMap contributors, Overture Maps Foundation.

The `gtfs-*-alignments.geojson` files are excerpts of the Overture Maps
transportation release `2026-10-21.0`, made available under the
[Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
Source segment IDs and attribution records are retained in each feature.
See [Overture's transportation attribution](https://docs.overturemaps.org/attribution/#transportation).

Modifications consist of selecting the documented segments, adding the
reference route and direction identifiers, and reversing coordinates for the
explicit opposite direction. The data licence is separate from the software
licence. See [the validation report](../GTFS_GENERATION.md) for provenance,
reference dates, checksums and limitations.
